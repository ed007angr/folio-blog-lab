# Folio — Angular

Блоговая платформа Folio на Angular: модуль `AppModule`, компоненты шапки, списка и карточки статьи, сервис с mock-данными.

Ветка `angular`. Ветка `main` остаётся с прототипом на Vue.

## Запуск

Нужны Node.js 18+ и npm. Команды выполняются из каталога `my-app`.

```bash
cd my-app
npm install
npm start
```

Приложение откроется по адресу http://localhost:4200/.

Сборка:

```bash
npm run build
```

Готовые файлы появятся в `my-app/dist/my-app`.
